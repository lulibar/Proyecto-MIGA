# RecetApp

Aplicación web (PWA) para explorar recetas de cocina, desarrollada como Trabajo Integrador de Aplicaciones Móviles.

## Tecnologías
- React (Vite)
- React Router
- TheMealDB API
- localStorage

## Instalación

\`\`\`bash
git clone https://github.com/tu-usuario/recetapp.git
cd recetapp
npm install
\`\`\`

## Ejecución

\`\`\`bash
npm run dev
\`\`\`

Abrir `http://localhost:5173` en el navegador.
